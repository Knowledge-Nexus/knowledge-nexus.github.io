# Repositório de dados — Knowledge Nexus

**Este repositório tem de ser PRIVADO.** Contém material de estudo com direitos de autor.
Nunca o tornes público, nunca actives o GitHub Pages aqui e partilha-o só com quem deve
ter acesso (a fronteira de segurança é o repositório).

- Envia material pela interface (https://knowledge-nexus.github.io), pelo `nexus vigiar`
  ou largando ficheiros em `deposito/__OWNER__/`.
- O workflow `nexus` processa o depósito a cada envio: guarda os originais em
  `originais/` (endereçados por SHA-256, nunca alterados), extrai o texto para `texto/`,
  classifica e arruma em `documentos/`. O que ficar ambíguo vai para "A rever".
- Os índices (SQLite) vivem no ramo `indices`, reescrito a cada execução.

Estrutura detalhada: `docs/repo-dados.md` no repositório da aplicação.
