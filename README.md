# Knowledge Nexus

Plataforma de estudo para o ensino superior. Deposita o material sem o organizar (PDFs,
slides, fotos de apontamentos, enunciados, resoluções, código, zips) e o sistema:

1. identifica cada ficheiro;
2. deduplica;
3. extrai o texto, com OCR em português;
4. classifica-o por cadeira, tipo, ano lectivo e época;
5. arruma-o numa biblioteca pesquisável.

- **Interface:** https://knowledge-nexus.github.io (só código; os teus dados nunca estão aqui).
- **Dados:** um repositório **privado** teu no GitHub, processado pelo GitHub Actions.
- **Começar:** [docs/configuracao.md](docs/configuracao.md).
- **Para quem desenvolve:** [CLAUDE.md](CLAUDE.md) e [docs/arquitectura.md](docs/arquitectura.md).

> Este repositório é público. Nunca coloques aqui material de estudo real: muito dele
> tem direitos de autor.
